# Strandbeest gripper v4: hand-operated, thumb wheel (GRIP-9007)

X1, not printed yet — **NEEDS PRINT TEST**. This is [v3a](../v3a_pivot-jaws/README.md) (two mirrored Jansen fingers with 25 mm pivoting jaws) **without a servo**: you drive it by rolling a knurled thumb wheel. Every part is 3D-printed; only standard M3 screws, nuts and two shoulder screws are bought. Overview of all versions: [../README.md](../README.md).

## How it works

- **Thumb wheel (GRIP-0035):** a 40-tooth gear (module 1) on top of a Ø50 knurled rim. It sits where the servo used to be, meshing with crank gear 1, and its rim overhangs the base by about 16 mm so you can roll it with a thumb.
- **Gearing:** one wheel turn gives **two crank turns**, so the jaws go through two full cycles: clamp → pull 19.9 mm → release → return.
- **Crank 1 (GRIP-0034):** turns on an M3 axle like crank 2, with a recessed thin nut, instead of on a servo horn.
- **Base (GRIP-0033):** a flat plate, 4 mm thick, that sits on the table. All axles and the G posts stand on it.
- **Everything above the gear layer is unchanged from v3a:** legs, gears, jaws, clamp gap 1.53 mm, opening 19.5 mm.

**Moving it in SolidCraft.** Open `cad/GRIP-9007_assy-thumb-wheel.sc` and drive the joint **`W_wheel`** (or drag the wheel). Crank 1 follows at −2×, and both fingers follow through the gear train.

## Hardware

Screw lengths are computed from the stack: grip + washer + nut, rounded up to a standard length.

| Qty | Item | Where |
|---|---|---|
| 1 | M3×30 + nyloc | thumb-wheel axle, from below the base |
| 2 | M3×22 + thin nut DIN 439 + threadlocker | crank 1 and crank 2 axles; the nut sits in the gear's top recess |
| 2 | M3×30 + nyloc | idler axles, from below the base |
| 2 | M3×45 + nyloc | G of each finger, from below through the base and post |
| 2 | ISO 7379 shoulder screw Ø4×25, M3 | J1 of each finger, screwed into the crank gear |
| 2 | M3×22 + nyloc | J2 |
| 2 | M3×12 + nyloc | J3 |
| 2 | M3×18 + nyloc | J4 |
| 2 | M3×22 + nyloc | J5 |
| 2 | M3×30 + nyloc | jaw pivots at F |
| ~26 | M3 washers 0.5 mm | between layers |

Snug the nyloc nuts but don't clamp them: everything must turn freely. Assembly order and gear timing are the same as [v2](../v2_dual-finger/README.md#assembly-notes). Time the thumb wheel last: with both fingers at θ = 0 (pads closed), drop the wheel onto its axle in whatever tooth gap fits.

All 17 PASS (latest run):

| Check | Result |
|---|---|
| Joints | 25 revolute + 2 parallel relations; no conflicts |
| Drive | full crank turn by driving `W_wheel` in 30° crank steps; every step moved |
| Joint traces (both fingers) vs `jansen.py` | 0.0016 mm |
| Jaw orientation over a full turn | constant (0.0000°); faces parallel, gap root = tip |
| Clamp gap / opening / pull stroke | 1.53 / 19.5 / 19.9 mm |
| Meshes, incl. thumb wheel / crank 1 (one pitch fine + full turn every 10°) | 0.141–0.142 mm, no overlap |
| Collisions (gears vs base, jaws vs all, links vs all, full turn) | none; closest 0.5 mm |

The first build failed the thumb-wheel check at 0.044 mm. Crank 1's J1 hub was sweeping over the wheel's tooth tips, because the gear tops were flush. The driven gears (idlers and wheel) are now 0.5 mm lower.
