# gripper_tips v2: open inside — SO101-0003, SO101-0004

Red snap-on calibration tips for the standard SO-101 follower gripper that **only cover the outside of each finger**. The gripping (inside) face stays bare, so the tips don't change how the gripper grips or how far it closes.

| Moving jaw (SO101-0003) | Fixed jaw (SO101-0004) |
|---|---|
| ![moving](docs/v2_moving-jaw_grip-face.png) | ![fixed](docs/v2_fixed-jaw_grip-face.png) |

## What changed from v1 ([`v1_full-cap/`](../v1_full-cap/README.md), SO101-0001/0002)

- **Front wall removed.** v1 was a full cap over the tip. v2 is a U-clip: outer back wall, two side walls and the tip end.
- **No material inside the gripping plane.** The clip stays `grip_setback` (0.5 mm) behind the outermost step of the straight gripping face:

  | | Gripping plane | Cap material ends at | Measured on the export |
  |---|---|---|---|
  | Moving jaw | x −12.3, faces −X | x −11.8 | bbox min x −11.80 ✓ |
  | Fixed jaw | x −7.9, faces +X | x −8.4 | bbox max x −8.40 ✓ |

- **Snap unchanged:** the same 1.2 mm bumps click into the jaw's Ø1.5 through-hole, which sits behind the gripping face (`model.faces`: moving at (−1.19, −58.66), ±Z; fixed at (−13.69, 88.33), ±Y). The front slit is gone together with its wall; the back slit stays so the side walls can flex.
- **Cavity unchanged:** same section envelope + `clr` 0.2 mm as v1. Only material was removed, so the fit can't get tighter than v1.
- Volume: moving 1679.9 mm³ (v1 2385.8), fixed 1046.1 mm³ (v1 1542.7). One body each.

**NEEDS PRINT TEST:** with the front open, the clip is held only by the bumps and the tip end; check that it stays on while the gripper closes on an object.

## Print

- Open mouth down (the end that slides onto the finger), no supports; set in `print_orient.json`, so the plate file and sorting sheet use it. Print height 27.8 mm (moving) and 21.2 mm (fixed).
- Red PLA or PETG, 2 or more perimeters (wall 1.6 mm).
- Plate: `exports/plates/v2_open-inside_plate1-petg_X1.3mf`. Sorting sheet: [`docs/v2_open-inside_sort-sheet_A4.pdf`](docs/v2_open-inside_sort-sheet_A4.pdf).

## Fit on

Slide each clip over its finger tip, open mouth first, until the bumps click into the hole. Pull it off toward the tip.
